# Sentencing Bias Data

This checkout ships the compact analysis dataset used for routine modeling and figure generation.

## In This Repo

| File | Description |
| --- | --- |
| `processed/sentencing_clean.parquet` | Evidence-gated analysis dataset (69,527 cases; public release omits direct identifiers and rejected factor fields) |
| `DATASHEET.md` | Dataset datasheet |
| `CODEBOOK.md` | Variable definitions |
| `validation/` | Prediction-blinded validation protocol and aggregate evidence |

## Source Archive

The full source-decision JSON files, extraction outputs, case-ID enumerations,
and case-level validation labels are not included in the public repository.
They are retained privately for provenance. The original decisions remain
available from shuukh.mn, subject to the judiciary's availability and terms.

## Quick Start

```python
import pandas as pd

df = pd.read_parquet("processed/sentencing_clean.parquet")
print(len(df))  # 69527
```

## Scope

- Study window: 2020-01-01 to 2026-02-04
- Full enumeration: 80,827 cases
- Valid decisions: 77,968
- Clean analysis sample after excluding the invalidated probation label: 69,527

## Canonical Analysis Samples

These definitions are generated by `tables/sample_registry.csv`:

- `full`: all cleaned cases
- `sample_a`: complete on `female`, `age`, `education_level`, `employed`, `crime_category`, `prior_criminal`, `severity`
- `sample_b`: complete on `female`, `education_level`, `employed`, `crime_category`, `prior_criminal`, `severity`
- `two_part_stage1`: complete on `female`, `age`, `education_level`, `employed`, `crime_category`, `prior_criminal`
- `two_part_stage2`: stage 1 plus non-missing `sentence_months` and imprisonment sentence type
